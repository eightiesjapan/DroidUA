User reported R1 immediately changed pointer/camera mode, preventing right-drag
map panning. R1 now toggles only on release of a short (<300 ms), stationary click.

2026-11-02 Hidden-overlay HUD touch consistency and VIEW/SELECT labels
Investigation: AndroidTouchEvent previously returned early when TouchEnabled was
false (Touch Hide, or Auto with gamepad). Thus RG477V used SDL synthetic mouse
coordinates while Pixel with visible controls used explicit absolute fingers.

across host/menu/control changes. Now all mission fingers use the same absolute
translation and suppress duplicate SDL touch-mouse events independently of overlay
visibility. TouchAxes clears all fingers only outside gameplay; hidden overlays
remove control fingers but retain direct gestures through release.

2026-11-03 RG477V digital L2/R2 compatibility fix
The built-in retrogame_joypad advertises trigger axes, but its Android L2/R2
key events are delivered as SDL raw joystick buttons 15/16, omitted from the
generated controller mapping. Read these digital signals in addition to analog
trigger axes for this named built-in pad only, avoiding unrelated HID buttons.
L2 duplicates A and R2 duplicates B, including held/released state. Added trigger
transition logs for diagnosis. Android build passed; installed in place on
RG477V. Logs confirm both L2 and R2 press/release transitions; user played and
confirmed both triggers shoot. Pixel awaits latest APK update.

2026-11-03 Map double-tap and controller double-click
Android-generated touch and L1 mouse events previously always had clicks=1,
so the engine never received FLAG_DBL_CLICK to enter a map vehicle. Added
independent click recognizers for direct fingers and gamepad clicks. Short
stationary click pairs within 350 ms emit clicks=2; drag motion (including
out-and-back paths), long holds, distant taps and resets cancel the pairing.
The map's Android release-position tolerance now accepts 12 logical pixels of
finger drift; desktop retains its original <4-pixel behaviour. Existing native
map transfer and automatic Look-on-vehicle-entry paths are reused.
Validation: click_gesture_test passes timing, position, drag, hold, reset and
controller cases. Android and Windows builds passed. Installed in place on
RG477V, preserving data. User asked to verify direct map double-tap and L1
